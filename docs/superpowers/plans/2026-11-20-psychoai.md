# PsychoAI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Azərbaycan dilində Gemini Live ilə səsli seans aparan, gündə 1 level, təqvim, tapşırıq və əhval izləmə olan sayt + 5 agentlik komanda və vizual ofis.

**Architecture:** Vite + vanilla JS SPA (`src/`). Gizli açar yalnız `api/*.js` serverless funksiyalarındadır (Vercel; lokalda Vite middleware eyni modulları çağırır). Brauzer Live-a qısaömürlü token ilə qoşulur. Bütün istifadəçi məlumatı `localStorage`-da bir `store` modulundadır.

**Tech Stack:** Node 26, Vite, Vitest, vanilla JS (ES modules), Gemini API (`gemini-3.8-live`, `gemini-3.8-flash`), Vercel.

**Spec:** `docs/superpowers/specs/2026-11-20-psychoai-design.md`

## Global Constraints
- UI mətni 100% Azərbaycan dilində (ə, ö, ü, ğ, ş, ç, ı düzgün).
- Live modeli: `gemini-3.8-live`; analiz modeli: `gemini-3.8-flash`.
- `GEMINI_API_KEY` yalnız serverdə (`process.env`); `src/` və `dist/` heç vaxt açarı ehtiva etmir.
- Palitra: `#FBF9F5` fon, `#F2EFE9` kart, `#356859` adaçayı, `#B8745B` gil, `#1B2A24` mətn; qaranlıq: `#101715`, `#192320`, `#88C0AC`. Şriftlər: Lora (başlıq), Plus Jakarta Sans (mətn).
- Bildiriş/zəng yoxdur. Gündə 1 level (server vaxtına görə, Asia/Baku).
- Böhran ifadəsində 112 və yaxınlara müraciət mesajı göstərilir.
- Fayllar agentlər tərəfindən yalnız Edit/Write ilə dəyişdirilir; hər agent yalnız öz sahəsindəki faylları dəyişir.

## Review Focus
1. Mikrofon icazəsi rədd edilir → aydın azərbaycanca izah, səhifə sınmır (Task 5 test: `LiveSession` `error` hadisəsi `mic-denied`).
2. Live bağlantısı seansın ortasında kəsilir → transkript itmir, "Yenidən qoşul" və ya "Görüşü tamamla" mümkündür (Task 5).
3. Gecə yarısı / saat dəyişdirilməsi → kilid server gününə əsaslanır (Task 3 test: `canStartLevel` server dayKey ilə).
4. Analiz JSON-u pozuq və ya şəbəkə xətası → seans yenə "tamamlandı" qeyd olunur, xülasəsiz; proqram sonra yenidən yaradılır (Task 3 test).
5. Böhran sözü transkriptdə → ekranda dərhal dəstək kartı (Task 4 test: `detectCrisis`).

**Interfaces (Produces):**
